# Интернет-магазин дизайнерских ламп «ОРБИТА»

## О проекте

«ОРБИТА» — многостраничный интернет-магазин дизайнерских ламп и предметов интерьера. Проект представляет собой адаптивный сайт с каталогом товаров, информационными страницами и интерактивными элементами.

Сайт выполнен в минималистичном стиле с использованием светлой цветовой гаммы, крупной типографики, фотографий товаров и интерьеров.

## Тема контрольной работы

**Тема:** «Разработка многостраничного сайта».

В текущей реализации проекта используются HTML, CSS и JavaScript. Для оформления и адаптивного поведения применяются собственные CSS-стили.

## Основные возможности сайта

Пользователь может:

- ознакомиться с ассортиментом дизайнерских светильников;
- посмотреть новые товары на главной странице;
- перейти в каталог;
- выбирать категории товаров;
- фильтровать товары по характеристикам и стоимости;
- применять и сбрасывать фильтры;
- сортировать товары по цене и названию;
- просматривать количество найденных товаров;
- открывать подробную информацию о товаре в модальном окне;
- изменять количество товара в карточке;
- добавлять товары в избранное;
- открывать и закрывать мобильное меню;
- просматривать ответы на часто задаваемые вопросы;
- заполнять форму обратной связи.

## Страницы сайта

### Главная страница — `index.html`

На главной странице представлены логотип магазина, навигационное меню, основной баннер с описанием магазина и кнопкой перехода в каталог, а также блок с новыми товарами.

Карточки товаров позволяют перейти к просмотру подробной информации о выбранном светильнике.

### Страница «О нас» — `about.html`

Страница содержит информацию о магазине, его концепции и ассортименте. Также на ней представлены фотографии интерьеров и информационные блоки.

### Страница «Каталог» — `catalog.html`

На странице размещён каталог дизайнерских светильников.

Реализованы следующие функции:

- выбор категории товаров;
- фильтрация по цвету, материалу и форме;
- фильтрация по дополнительным характеристикам через списки выбора;
- настройка минимальной и максимальной стоимости;
- применение выбранных фильтров по нажатию кнопки;
- сброс параметров фильтрации;
- сортировка по возрастанию и убыванию цены, а также по названию;
- отображение количества найденных товаров;
- сообщение при отсутствии подходящих товаров;
- открытие модального окна с подробной информацией о товаре;
- изменение количества товара в модальном окне;
- добавление товаров в избранное.

### Страница «Контакты» — `contacts.html`

На странице размещена контактная информация магазина: телефон, электронная почта, адрес и график работы.

Также представлены форма обратной связи и раздел часто задаваемых вопросов (FAQ). При отправке формы отображается благодарственное сообщение, после чего поля формы очищаются.

## Адаптивность и навигация

Сайт адаптирован для просмотра на компьютерах, планшетах и мобильных устройствах.

## Организация CSS и JavaScript

Для удобства разработки стили разделены на отдельные файлы:

- `normalize.css` — нормализация стандартных стилей браузера;
- `style.css` — основные стили сайта;
- `media.css` — адаптивные стили для разных размеров экранов;
- `modal.css` — оформление модальных окон;
- `footer.css` — оформление подвала сайта.

В файле `js/main.js` находится JavaScript-код, отвечающий за работу модальных окон, мобильной навигации, фильтров, сортировки каталога, избранного, FAQ и формы обратной связи.

## Инструкция по запуску

Для просмотра опубликованного сайта перейдите по ссылке GitHub Pages.

Для локального просмотра:

1. Скачайте или клонируйте репозиторий.
2. Сохраните исходную структуру папок и файлов.
3. Откройте `index.html` в браузере.
4. Для просмотра отдельных разделов используйте соответствующие HTML-файлы.

Страницы проекта:

- `index.html` — главная страница;
- `about.html` — страница «О нас»;
- `catalog.html` — каталог товаров;
- `contacts.html` — страница контактов.
