# Интернет-магазин дизайнерских ламп «ОРБИТА»

## Название проекта

Интернет-магазин дизайнерских ламп «ОРБИТА».

## Разработка HTML, CSS, JavaScript и Bootstrap

«ОРБИТА» --- многостраничный интернет-магазин дизайнерских ламп и
предметов интерьера. Проект разработан с использованием HTML, CSS,
JavaScript и Bootstrap 5.3.3.

Сайт сохраняет оригинальный минималистичный дизайн и структуру страниц.
Bootstrap используется для адаптивной сетки, вспомогательных классов и
мобильной навигации, а собственные CSS-стили применяются для сохранения
фирменного оформления.

## Тема контрольной работы

**Тема:** «Разработка многостраничного сайта с использованием Bootstrap».

В рамках контрольной работы реализован многостраничный сайт
интернет-магазина дизайнерских ламп «ОРБИТА». Основная задача проекта
--- создать адаптивный интерфейс интернет-магазина с несколькими
страницами, каталогом товаров, карточками продукции, формой обратной
связи и интерактивными элементами.

## Краткое описание проекта

«ОРБИТА» --- интернет-магазин дизайнерских ламп и предметов декора для
интерьера.

Сайт выполнен в минималистичном стиле со светлой цветовой гаммой,
крупными типографическими элементами, фотографиями интерьеров и
скруглёнными элементами интерфейса.

На сайте пользователь может:

-   ознакомиться с ассортиментом дизайнерских ламп;
-   посмотреть новые товары;
-   перейти в каталог;
-   использовать фильтры и сортировку товаров;
-   открыть карточку товара в модальном окне;
-   ознакомиться с описанием и стоимостью товара;
-   перейти на страницу «О нас»;
-   найти контактную информацию;
-   заполнить форму обратной связи;
-   просматривать сайт на компьютерах, планшетах и мобильных
    устройствах;
-   открывать мобильное боковое меню нажатием на кнопку с тремя
    полосками.

-   **HTML5** --- структура страниц;
-   **CSS3** --- оформление, фирменный дизайн и адаптивные стили;
-   **JavaScript** --- интерактивность сайта;
-   **Bootstrap 5.3.3** --- адаптивная сетка, вспомогательные классы и
    компонент мобильной навигации.

Bootstrap подключается через CDN, поэтому для загрузки его CSS и
JavaScript необходимо подключение к интернету.

## Инструкция по просмотру проекта

Для просмотра сайта можно открыть `index.html` в браузере или перейти по
ссылке GitHub Pages.

Для просмотра отдельных страниц используются файлы:

-   `index.html` --- главная страница;
-   `about.html` --- страница «О нас»;
-   `catalog.html` --- каталог товаров;
-   `contacts.html` --- страница контактов.

При локальном просмотре необходимо сохранить структуру папок, чтобы
ссылки на CSS, JavaScript, изображения, шрифты и иконки продолжали
работать.

## Описание обязательных страниц

### Главная страница --- `index.html`

На главной странице представлены логотип магазина «ОРБИТА»,
навигационное меню, основной баннер с описанием магазина и кнопкой
перехода в каталог, а также блок с новыми товарами.

### Страница «О нас» --- `about.html`

Страница содержит информацию о магазине, описание концепции, фотографии
интерьеров и статистические показатели.

### Страница «Каталог» --- `catalog.html`

На странице каталога представлены дизайнерские лампы в виде карточек
товаров. Реализованы категории, фильтры, сортировка и интерактивное
открытие карточки товара в модальном окне.

### Страница «Контакты» --- `contacts.html`

На странице размещена контактная информация магазина: телефон,
электронная почта, адрес и график работы. Также представлены форма
обратной связи и изображение интерьера.

## Адаптивность и навигация

Сайт адаптируется под экраны компьютеров, планшетов и мобильных
устройств.

-   На широких экранах отображается горизонтальная навигация.
-   На узких экранах горизонтальное меню заменяется кнопкой с тремя
    полосками.
-   При нажатии на кнопку открывается боковая панель навигации.
-   Ссылки мобильного меню ведут на соответствующие страницы сайта.
-   Для сетки и адаптивного поведения используются возможности
    Bootstrap, а для фирменного оформления --- собственные CSS-стили.
